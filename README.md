# 📝 Desain Accordion Slider Web

## Desain Accordion Slider Web dengan HTML, CSS, dan JavaScript

Proyek web yang mendemonstrasikan pembuatan accordion slider responsif menggunakan HTML untuk struktur, CSS untuk animasi, dan JavaScript untuk interaktivitas, termasuk navigasi dan efek hover.

---

### 📖 Deskripsi Proyek
**Desain_Accordion_Slider_Web** adalah proyek berbasis web yang menunjukkan cara membuat accordion slider untuk menampilkan informasi mobil dengan desain responsif. Program ini menggunakan HTML untuk tata letak slider, CSS untuk efek visual seperti animasi transisi, filter grayscale, dan responsivitas, serta JavaScript untuk fungsi interaktif seperti navigasi dengan tombol dan keyboard.

#### Fokus Proyek:
- 📊 **Struktur HTML:** Membuat slider dengan beberapa slide berisi detail mobil (BMW M3, Audi RS6, Mercedes-AMG, Porsche 911) dan elemen navigasi.
- 🔍 **Styling CSS:** Menerapkan desain modern dengan gradient, efek hover, transisi cubic-bezier, dan media query untuk adaptasi layar kecil.
- 🔍 **Interaktivitas JavaScript:** Menambahkan fungsi untuk mengaktifkan slide, navigasi dengan tombol sebelum/sesudah, dan kontrol keyboard (Arrow Left/Right).

Proyek ini ideal untuk pemula yang ingin mempelajari desain web responsif, animasi CSS, dan pemrograman JavaScript dasar.


---

### 🟢 Catatan
- Pastikan semua file (`index.html`, `style.css`, `script.js`) berada di direktori yang sama.
- Gambar latar diambil dari **Unsplash** dan membutuhkan koneksi internet untuk memuatnya.
- Efek animasi menggunakan `transition: all 0.5s cubic-bezier(0.4, 0, 0.2, 1);` dengan efek `filter: grayscale` saat hover.
- Responsif dengan `media query` untuk tampilan mobile.
